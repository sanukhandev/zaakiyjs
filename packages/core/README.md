# @zaakiyjs/core

**M0 contract-only scaffold; framework functionality is NOT implemented.**

Types are design contracts for the seven parallel implementation agents. The only runtime export is `foundationStatus`; never interpret a successful import/build as implemented functionality. See [shared contracts](../../docs/contracts/README.md) before adding runtime exports.

No npm publication is authorized by M0. Verify scope ownership, public API, licensing and pack contents before any release.
