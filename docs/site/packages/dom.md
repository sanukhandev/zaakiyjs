# @zaakiyjs/dom

Use DOM at runtime for precise native node updates generated by the compiler, not JSX interpretation.

> **Availability:** Implemented source package in the repository, not a verified public npm release. All package manifests on the referenced commit are `0.0.0`; install from this workspace until independent publishing is approved.

## At a glance

- **Primary use:** Let the compiler generate bindings in app code. Use low-level helpers primarily for integration adapters, tests and compiler internals.
- **Runtime boundary:** See the package README and public export map before importing into browser/server code.
- **Source revision:** [9f6c6603c98c](https://github.com/sanukhandev/zaakiyjs/commit/9f6c6603c98ca566c2fed6fed34cc770f6a72960).

## Feature usage: first working pattern

```ts
import { mount } from '@zaakiyjs/dom';
import { createElement, createText, bindText, listen } from '@zaakiyjs/dom/compiler';
import { signal } from '@zaakiyjs/signals';

const clicks = signal(0);
const handle = mount(owner => {
  const button = createElement('button', 'html');
  const text = createText('');
  button.append(text);
  bindText(owner, text, () => `Clicks: ${clicks.value}`);
  listen(owner, button, 'click', () => { clicks.value++; });
  return button;
}, document.getElementById('app')!);
// Later: handle.dispose();
```

## Usage and correctness guidelines

- The mount handle owns only its inserted DOM range; it does not clear unrelated container children.
- Do not pass HTML strings, unsafe URL schemes or dynamic inline event handlers.
- Keyed region helpers preserve node identity and reject duplicate keys. Higher-level TSX support is constrained by the compiler.

## Detailed feature guide

Sections below retain capability explanations and examples from the package's source README, not unimplemented proposals. Technical limitations inside a section remain applicable.

### Public browser modules

- `@zaakiyjs/dom`: `mount(compiledFactory, container)` initializes a fresh owner once; `dispose()` cleans up and removes only its mounted range.
- `@zaakiyjs/dom/compiler`: frozen v1 primitives `createElement`, `createText`, `setText`, `setProperty`, `setAttribute`, `bindText`, `bindProperty`, and `listen`.
- Additional browser helpers: `setClass`, `setStyle`, `bindAttribute`, `bindClass`, `bindStyle`, `bindRef`, `bindMountedRef`, `listenStable`, and `cloneStatic`.

`bind*` functions connect render-phase signal effects to core owner cleanup. A read tracks only signals accessed by that binding. `setText` updates `Text.data` only when changed. Reactive boolean or nullish JSX children normalize to empty text, matching the compiler's nonreactive lowering. Immutable templates are constructed DOM nodes cloned with `cloneNode(true)`; HTML strings are never parsed.

### Hand-authored compiler ABI fixture

```ts
const count = signal(0);
const app = mount((owner) => {
  const button = createElement("button", "html");
  const text = createText("");
  button.append(text);
  bindText(owner, text, () => count.value);
  listen(owner, button, "click", () => { count.value += 1; });
  return button;
}, document.querySelector("#app")!);
app.dispose();
```

The example illustrates the compiler's native-DOM ABI. Supported TSX is compiled to these runtime operations at build time; no generic JSX interpreter or React-style runtime fallback is used.

### Internal region machinery

`src/regions.ts` implements scoped conditional regions and keyed range moves. It is deliberately **not** a package export. Compiler ABI for loops, range marker shape, `<Show>` and `<For>` requires a coordinated ADR before release. Duplicate keys throw before DOM changes; matching keys retain their item owners and native nodes.

### Security

- Text is never injected as HTML.
- Dynamic inline event attributes and HTML sinks are forbidden.
- URL-bearing bindings are scheme-validated; `srcset` is rejected pending an approved URL-list policy.
- Arbitrary CSS URLs and legacy executable CSS functions are rejected.
- Static-clone helper accepts constructed DOM nodes only; no `innerHTML`, `eval`, or `new Function`.
- Standard native events and owner cleanup; no global async patches.

### Compiler-generated regions (ABI v1)

The public browser subpath `@zaakiyjs/dom/compiler` now exports `createRegion`, `bindConditionalRegion`, and `bindKeyedRegion` alongside the primitive binding operations. The conditional helper supports an optional alternate branch factory; each active branch receives a scoped child owner and deterministic cleanup. The keyed helper preserves stable node/focus identity and rejects duplicate primitive keys before DOM mutation. Replacing an item with the same key requires an explicit `KeyedView.update(next)` callback so stale content cannot be silently retained.

See [ADR 0004](../../adr/0004-dom-region-abi.md) for the frozen protocol and its restrictions. Compiler support for every TSX syntax form is a **separate acceptance gate**; the public ABI alone does not establish complete `<Show>`/`<For>` compilation or SSR/hydration.

### Connected native refs versus eager refs

`bindRef(owner, node, callback)` retains its existing eager callback semantics for compatibility with legacy DOM ABI consumers. The additive `bindMountedRef(owner, node, callback)` is designed for compiler-generated native JSX and invokes the callback only once the node is connected. A disconnected mount uses a scoped `MutationObserver` until connection; owner disposal disconnects the observer and sends a single `null` after a successful attachment. It does not provide a component-instance ref, slot ownership protocol, or server hydration support. Native TSX `ref` lowering is conditional, so modules not using refs do not import the extension.

### Compiler-generated reactive classes and attributes

The hardening compiler now emits `bindClass` for finite class-variant expressions and `bindAttribute` for reactive non-URL attributes. These reuse established owner-scoped effects and the native `setAttribute` URL/sink policy, retaining element identity across updates. The compiler never accepts arbitrary user-generated utility names or bypasses the verified Vite CSS token-offset contract. Dynamic URL expressions and inline style objects remain unsupported; runtime `setStyle` is not an implicit authorization for compiler-generated inline styles under strict CSP.


### Additive exit-aware DOM integration

\`@zaakiyjs/dom/compiler\` additionally exposes \`bindExitAwareConditionalRegion\` for direct native DOM integration. It retains one element/owner while \`exit(element, signal)\` settles, cancels pending exit on re-entry, and enforces a bounded 1–30000ms lifetime. Parent disposal is synchronous and aborts pending exits. Existing \`bindConditionalRegion\` and keyed-region behavior remain unchanged; this helper is not emitted automatically by TSX and does not support fragments, slots or nested keyed exit choreography.
